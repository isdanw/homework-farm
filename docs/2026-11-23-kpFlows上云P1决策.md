## 决策

1. **架构例外成立**：工作台「云端直连·只读零回写」的口子从「仅 orders」扩到「orders ＋ kpflows」，同款收窄纪律（专用写函数、单键 payload、身份不入端、单一调用方）。
2. **本期只做 P1**（工作台→云端单向备份）；P2 读回/多设备、P3 小程序侧读写待 P1 稳定后另立任务。
3. **云端存整流快照**（非事件流）；**立即推＋失败重试队列**（队列落 localStorage，latest-wins）。

## 契约

- 集合 `kp_flows`，`_id = flowId`（幂等去重）；`clientId = flowId`（E2E 清理白名单统一）。
- 字段白名单重建 doc：subject / knowledgePoint / status / step / reviewRound / nextReviewAt / lastEvidence / prevStatus / createdAt / updatedAt / deletedAt；多余键（含身份键）一律丢弃。
- 冲突裁决：per-flow LWW（updatedAt，ISO 字典序）→ tie 取 reviewRound 大者 → 再 tie 取云端。
- **通关只进不出**：云端已 cleared 不可被非 cleared 覆盖（证据链不断）。
- 云端只做事实记录：不推进状态、不算掌握度、不写 evidence；本地状态机唯一权威。
- P1 不改任何读路径：webAdminQuery sync 载荷不读本集合。

## P2 补充（2026-11-23 晚，读回/多设备）

- **learnerNo 口径**：值 = 云端孩子 id（`sync profile.childId`，即 hw_farm_user `data.users[].id`）——与小程序 `users.find(id===currentUserId)` 同源，P3 免适配。工作台 `meta.learnerId` 是 learnerNo 回落链（会落 'cloud-learner'），不是稳定孩子键，**不得**用作 learnerNo。
- **回填口径**：P1 旧 doc 无 learnerNo → 首拉按当前孩子回填 + `legacy=true`；只回填当前孩子，不猜其他孩子。
- **合并**：per-flow LWW（updatedAt）→ ≤5 分钟时钟差窗口取 reviewRound 大者 → 再 tie 取云端；通关只进不出（双向）；deletedAt 按删除处理；本地独有流永不删除；**合并不产生备份事件**。
- **截断**：未通关全量 + 已通关按 updatedAt 倒序最近 100；`truncated=true` 界面 toast 明示。
- **版本**：SNAPSHOT_CONTRACT_VERSION / SNAPSHOT_SCHEMA_VERSION 保持 v1（validateSnapshot 精确相等，升版旧快照全报不兼容）；CLOUD_MAPPER_VERSION 升 cloud-adapter-v2。
- 已知留白：本地删除流目前无 UI 入口（墓碑字段已就位）；本地墓碑与云端活跃行的冲突走 LWW，无特殊分支。
