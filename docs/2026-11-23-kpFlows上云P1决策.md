## 决策

1. **架构例外成立**：工作台「云端直连·只读零回写」的口子从「仅 orders」扩到「orders ＋ kpflows」，同款收窄纪律（专用写函数、单键 payload、身份不入端、单一调用方）。
2. **本期只做 P1**（工作台→云端单向备份）；P2 读回/多设备、P3 小程序侧读写待 P1 稳定后另立任务。

## 契约

- 集合 `kp_flows`，`_id = flowId`（幂等去重）；`clientId = flowId`（E2E 清理白名单统一）。
- 字段白名单重建 doc：subject / knowledgePoint / status / step / reviewRound / nextReviewAt / lastEvidence / prevStatus / createdAt / updatedAt / deletedAt；多余键（含身份键）一律丢弃。
- 冲突裁决：per-flow LWW（updatedAt，ISO 字典序）→ tie 取 reviewRound 大者 → 再 tie 取云端。
- **通关只进不出**：云端已 cleared 不可被非 cleared 覆盖（证据链不断）。
- 云端只做事实记录：不推进状态、不算掌握度、不写 evidence；本地状态机唯一权威。
- P1 不改任何读路径：webAdminQuery sync 载荷不读本集合。
